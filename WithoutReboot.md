# Change the Android ID without a reboot

Android loads the Android IDs (SSAID) of all apps when the device starts. A new ID that Device ID
Changer saves normally takes effect only after a reboot.

**Instant Apply** removes that reboot. When you tap **Save**, the new ID is applied right away. Only
the app you changed is stopped, so it picks up the new ID while the rest of the phone keeps running.
You can also turn on **Clear the app's data** to clear that app's data after the new ID is applied.

## How to set it up

1. Install the free app from [GitHub Releases](https://github.com/sdex/AndroidIDeditorV2/releases/latest)
   and grant it root access.
2. Check your phone before you buy: open **Instant apply → Compatibility → Learn more → Run checks**.
   The check tells you what your phone needs.
3. Get a license on the [Instant Apply page](https://sdex.dev/iap/) and activate it in the app under
   **Instant apply**.
4. Follow the setup card. Many phones need nothing more. Others use Zygisk or
   [Vector](https://github.com/JingMatrix/Vector), and setup asks for at most one reboot.

After setup, every ID you save applies without a reboot.
